# 🎲 Pig Game

A fun and interactive two-player dice game built with **HTML, CSS, and Vanilla JavaScript**. Challenge your opponent, roll the dice, collect points, and be the first player to reach the winning score!

## 🚀 Live Demo

[**Play Pig Game**](https://elyardev.github.io/Pig-Game/)

A classic two-player dice game with a clean interface, dynamic score updates, and interactive gameplay.

## ✨ Features

- 🎲 Interactive dice rolling system
- 👥 Two-player turn-based gameplay
- 🏆 Dynamic score tracking
- 🔄 Switch turns automatically when rolling a 1
- 💾 Hold button to save current points
- 🎮 New Game functionality to restart the game
- 🎨 Clean and user-friendly interface
- ⚡ Smooth and interactive gameplay

## 🎯 Game Rules

1. The game starts with Player 1.
2. Players take turns rolling the dice.
3. Each roll adds its value to the current score.
4. Rolling a **1** ends your turn and resets your current score.
5. Click the **Hold** button to save your current score to your total score.
6. The first player to reach **100 points** wins the game!

## 🛠️ Technologies Used

- **HTML5** – Structuring the game interface.
- **CSS4** – Styling and designing the user interface.
- **JavaScript (ES6+)** – Game logic, DOM manipulation, event handling, and dynamic interactions.
